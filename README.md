# Esoteric Ebb 简体中文汉化补丁

[Esoteric Ebb](https://store.steampowered.com/app/2057760/Esoteric_Ebb/) 的社区简体中文汉化补丁。当前版本：**v2.3.8**

>
> 游戏开发者已着手为 Esoteric Ebb 加入**官方本地化框架**。
>
> 因此，**v2.3.8 是当前 BepInEx 运行时架构（v2.x）的收官版本**。后续的汉化补丁将迁移到游戏官方的本地化框架上重新适配，版本号从 **v3.0** 起算：
>

> - 文本按稳定 ID 索引，游戏更新后翻译不会错位失效
>
> 官方本地化框架目前仍在开发者的内测阶段。在它正式随游戏发布之前，正式版分支的玩家请继续使用 **v2.3.8**。

> 🎉 **v2.3.8 亮点** —— 累计合并汉化组团队 ParaTranz 精修 **7,900+ 条**；修复递归卡死、过图卡顿、检定结果与短句漏翻、术语描述显示不全等一批玩家反馈问题；补丁包 ~53MB。
>
> ⚠️ **安装汉化补丁前，请先完全卸载游戏再重新安装游戏本体**（纯运行时架构需要干净的英文游戏资产作为基线，详见[安装方法](#安装方法)）。

## 安装方法

> **v2.3.x 采用纯运行时架构**：补丁只提供字体 + BepInEx 翻译插件 + 翻译字典，文本在游戏运行时翻译，**不再修改游戏数据文件**。因此安装前必须确保游戏资产是**干净的英文基线**。

1. **（重要）请先完全卸载游戏再重新安装游戏本体**，确保干净英文基线。
2. 在 [Releases](../../releases) 页面下载最新版本的 zip 压缩包（约 53MB）
3. 将压缩包内容全部**解压到游戏安装目录**（选择全部覆盖）：
   ```
   ..\Steam\steamapps\common\Esoteric Ebb\
   ```
4. 确认游戏根目录中存在 `winhttp.dll` 和 `doorstop_config.ini`（BepInEx 加载器）
5. 启动游戏即可看到中文界面

## 卸载方法

在 Steam 中：**右键游戏 → 属性 → 已安装文件 → 验证游戏文件完整性**

这会将所有修改过的游戏数据文件恢复为原始状态。如需彻底移除 BepInEx，还需手动删除游戏根目录中的 `winhttp.dll`、`doorstop_config.ini`、`.doorstop_version`、`BepInEx/` 文件夹和 `dotnet/` 文件夹。

## 常见问题

**Q：装上补丁后游戏一启动就崩溃 / 报错停止工作？**

请检查是否同时安装了 **XUnity.AutoTranslator**（通用自动翻译器）之类的翻译类 mod。它和本补丁都会挂钩游戏的文本组件，两者冲突会直接导致崩溃。**请卸载 XUnity.AutoTranslator**（删除 `BepInEx/plugins` 下的相关文件），本补丁自带完整中文，不需要再装任何自动翻译器。

**Q：装了汉化后，"连续点击 10 个术语词条"的成就无法达成？**

这是已知问题。汉化的中文术语高亮机制会干扰该成就的连击计数。**临时解决办法**：在设置里切回英文，连续点击 10 个术语拿到成就后再切回中文（成就是账号级的，不会丢失）。此问题仅影响这一个成就，不影响剧情与其它成就。
