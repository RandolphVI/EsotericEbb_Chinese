# Esoteric Ebb 简体中文汉化补丁

[Esoteric Ebb](https://store.steampowered.com/app/2057760/Esoteric_Ebb/) 的社区简体中文汉化补丁。当前版本：**v2.3**

> 🎉 **v2.3 新增：纯运行时架构** —— 补丁包从 ~450MB 瘦身至 ~56MB，根治旧版补丁部分老问题；大规模漏翻补全（气泡文本、会话日历、区域标题、短句等）。
>
> ⚠️ **安装汉化补丁前，请先完全卸载游戏再重新安装游戏本体**（纯运行时架构需要干净的英文游戏资产作为基线，详见[安装方法](#安装方法)）。

## 特性

- **77,000+ 条文本翻译**，覆盖对话、任务、角色创建、UI 界面
- **纯运行时架构** — 根治旧版补丁部分老问题；补丁包仅 ~56MB
- **286 个 Ink 故事文件**完整翻译，涵盖全部游戏剧情对话
- **主菜单、角色创建界面**中文化 — 六大属性、子职业、背景专长
- **游戏内 UI 全中文化** — 法术书、物品栏、属性面板、任务日志、交互气泡文本、区域标题、会话日历等
- **词汇表术语高亮**（680+ 条术语，点击可查看说明）
- **BepInEx 翻译插件**深度 hook，覆盖动态 UI 文本、法术描述、感知检定结果、短句对话等运行时文本
- **字体图集升级** — 大幅改善可读性
- **汉化组团队人工精修** — 在机翻基础上持续校对润色，质量稳步提升

## 安装方法

> **v2.3 采用纯运行时架构**：补丁只提供字体 + BepInEx 翻译插件 + 翻译字典，文本在游戏运行时翻译，**不再修改游戏数据文件**。因此安装前必须确保游戏资产是**干净的英文基线**。

1. **（重要）请先完全卸载游戏再重新安装游戏本体**，确保干净英文基线。
2. 在 [Releases](../../releases) 页面下载最新版本的 zip 压缩包（约 56MB）
3. 将压缩包内容全部**解压到游戏安装目录**（选择全部覆盖）：
   ```
   ..\Steam\steamapps\common\Esoteric Ebb\
   ```
4. 确认游戏根目录中存在 `winhttp.dll` 和 `doorstop_config.ini`（BepInEx 加载器）
5. 启动游戏即可看到中文界面

## 卸载方法

在 Steam 中：**右键游戏 → 属性 → 已安装文件 → 验证游戏文件完整性**

这会将所有修改过的游戏数据文件恢复为原始状态。如需彻底移除 BepInEx，还需手动删除游戏根目录中的 `winhttp.dll`、`doorstop_config.ini`、`.doorstop_version`、`BepInEx/` 文件夹和 `dotnet/` 文件夹。

## 🌐 翻译与反馈

汉化补丁的翻译来自机器翻译 + 汉化组人工精修校对，仍在持续打磨中。翻译数据托管于 [Paratranz](https://paratranz.cn/projects/18960)。
