# Esoteric Ebb 简体中文汉化补丁

[Esoteric Ebb](https://store.steampowered.com/app/2057760/Esoteric_Ebb/) 的社区简体中文汉化补丁。当前版本：**v2.1**

> 🎉 **v2.1 新增：[Paratranz 社区协作翻译](#-参与-paratranz-社区协作翻译精修)** —— 欢迎所有玩家一起来润色翻译质量！项目地址：https://paratranz.cn/projects/18960

## 特性

- **74,000+ 条文本翻译**，覆盖对话、任务、角色创建、UI 界面
- **286 个 Ink 故事文件**完整翻译，涵盖全部游戏剧情对话
- **主菜单、角色创建界面**中文化 — 六大属性、子职业、背景专长
- **游戏内 UI 全中文化** — 法术书、物品栏、属性面板、任务日志等
- **词汇表术语高亮**（680+ 条术语，点击可查看说明）
- **BepInEx 翻译插件**深度 hook，覆盖动态 UI 文本、法术描述、感知检定结果等运行时文本
- **运行时漏翻收集**机制 — 玩家可自动 dump 漏翻文本帮助下一版本补全
- **字体图集升级** — 大幅改善可读性
- **Paratranz 社区协作**接入 — 任何玩家都可参与翻译润色

## 安装方法

1. 在 [Releases](../../releases) 页面下载最新版本的 zip 压缩包
2. 将压缩包内容**解压到游戏安装目录**（选择全部覆盖）：
   ```
   ..\Steam\steamapps\common\Esoteric Ebb\
   ```
3. 确认游戏根目录中存在 `winhttp.dll` 和 `doorstop_config.ini`（BepInEx 加载器）
4. 启动游戏即可看到中文界面

## 卸载方法

在 Steam 中：**右键游戏 → 属性 → 已安装文件 → 验证游戏文件完整性**

这会将所有修改过的游戏数据文件恢复为原始状态。如需彻底移除 BepInEx，还需手动删除游戏根目录中的 `winhttp.dll`、`doorstop_config.ini`、`.doorstop_version`、`BepInEx/` 文件夹和 `dotnet/` 文件夹。

### 📁 文件结构（37 个 CSV，共 73,000+ 条）

我按"内容来源"把所有翻译条目分成了 37 个文件，方便你挑选熟悉的领域：

| 文件 | 内容 | 推荐译者 |
|---|---|---|
| `02_glossary.csv` | **术语表（最重要）** — 专有名词、地名、人名、法术名等 | 想统一术语的人优先翻这个 |
| `03_ink_AR.csv` ~ `32_ink_WL.csv` | **Ink 对话脚本**（30 个文件，按出场角色/区域分组） | 喜欢某个 NPC 或场景的人 |
| `01_feats.csv` | D&D 专长卡描述 | 熟悉 D&D 5e 的玩家 |
| `34_level_ui.csv` | UI 元素（导航、按钮、提示） | 任何人 |
| `36_quests.csv` | 任务点描述 | 跟过任务流程的人 |
| `37_sheet_info.csv` | 角色卡职业/背景 | 熟悉角色创建的人 |

进入 Paratranz 后，每条翻译都标注了来源（如 `[ink: AR_CoastMap.json:...]`），方便你快速定位上下文。

### ⚠️ 核心翻译规则（很重要！）

请翻译时务必遵守：

1. **保留所有 `<...>` 标签原样**：`<i>`、`<b>`、`<color=#xxx>`、`<size=70%>`、`<smallcaps>`、`<noparse>` 等。**只翻译标签之间的文字**。
   - ❌ 错：`<尺寸=70%>第2天</尺寸>`（标签被翻译，游戏会崩溃）
   - ✅ 对：`<size=70%>第2天</size>`

2. **保留所有 `{xxx}` 变量占位符原样**：花括号及内部内容**绝不要翻译**，那是游戏运行时变量。
   - ❌ 错：`你好，{玩家名}`
   - ✅ 对：`你好，{playerName}`

3. **保留 `\n` 换行符**：原文里有的换行不要删除（哪怕看起来多余）。

4. **全大写如 `TRINKETS`、`AGRARIAN` 等是游戏内枚举名**：译为对应中文（如"小饰品"、"农耕者"）。

5. **场景名按惯例不译**：如 `Lower Lair`、`Visken's Lair` 等保留英文（Paratranz 上 Context 列已标注）。

6. **术语统一参考 `02_glossary.csv`**：先翻这个文件，让其他译者参考你的术语选择。
